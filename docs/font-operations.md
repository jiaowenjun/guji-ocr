# 字体操作留痕登记簿

当前正式补录共十四项：大字标准码位 **U+2BD6E、U+2E85、U+2023F**，以及仅用于 `guji-plane0.ttf` 的 **PUA U+E701 v4、U+E704 v1、U+E705 v1、U+E706 v1、U+E707 v3、U+E708 v1、U+E709 v1、U+E710 v1、U+E711 v1、U+E712 v1、U+E713 v1**。各项来源、编码结论、操作时间线与详报入口见[字体补录 Changelog](font-changelog.md)；其中 U+E706、U+E707 保存已编码字符 U+343A、U+4F3A 的项目字形异体，不是新的通用字符。2026-11-18 对 U+2BD6E、U+E701 的资料汇编属于只读核验，不计新增字体操作。

制度自 2026-11-14 起执行（用户要求：**凡对字体的自定义优化、更新等操作，必须留痕记录**）。本登记簿是人读的汇总台账，与脚本自动追加的机器流水 `var/unencoded/kangxi-unencoded/font-patches.jsonl`（gitignore 内）互为备份——**双轨都要有**：脚本跑完有 jsonl，人做完（或复核完）来本页登记一行。自 2026-11-19 起，补录的强制清单、四层验收与完成定义以[字体补录规范](font-replenishment-spec.md)（v1）为准。

全部正式补录、修改、撤销及临时试验见[字体补录 Changelog](font-changelog.md)。本页负责操作制度与当前哈希基线，changelog 负责历史状态和详细报告入口。

## 登记规范

**必须登记的操作**（不限于补录）：

| 类别 | 例 |
| --- | --- |
| 字形补录 / 修改 | 向 ttf 注入新字形、改既有字形轮廓 |
| 字体文件替换 | 换版本、重建、重新拆分平面 |
| 缓存戳变更 | index.css `?v=` 递增（无论是否伴随字形变化） |
| 系统字体同步 | `~/Library/Fonts/` 下的同名字体操作（含备份/回滚） |
| 哈希基线漂移排查 | 复核发现字体文件意外变动 |

**每条登记必填字段**：

1. 日期与时间、操作者（脚本名 / 人）；
2. 对象文件的**前后 SHA-256 与字节数**（`shasum -a 256`）；
3. 操作内容与参数（码位、字形源、校准锚等）；
4. 验证手段与数值（chamfer 分、cmap 计数、渲染对比）；
5. 缓存戳（若涉及 index.css）；
6. git 提交哈希（仓库内字体文件变更必须伴随提交，二进制 blob 即历史回滚点）；
7. 回滚点（git blob / 备份文件路径）。

**文档同步范围**：正式补录除本登记簿与 Changelog 外，还要提供详报、机器证据，并更新[文档导航](README.md)、[证据索引](research/evidence/README.md)。改变工具适用范围或应用字体覆盖时，同步[补录流程](research/2026-11-13-kangxi-字体补录流程.md)及[应用字体说明](../guji-preview-grid/README.md#字體)。旧报告和 `current-fonts.json` 的统计／哈希保持当时快照，补充后续事件入口；标准 Unicode 字位不写入 PUA 专用注册表。
