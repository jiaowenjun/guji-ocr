## 历史勘误与维护规则

**U+2BD6E 区块名称勘误**：早期报告记作 Ext-C，实际为 **CJK Unified Ideographs Extension E（U+2B820–U+2CEAF）**；2026-11-18 直接核对 [Unicode Blocks.txt](https://www.unicode.org/Public/UCD/latest/ucd/Blocks.txt)。此文字错误不改变码位身份、补录对象及实际字形，旧文的 Ext-C 不应继续作为区块事实引用。

后续新增、替换、撤销均单独列事件，记录身份／用途、时间、对象、前后哈希与字节数、缓存戳、验证、提交和回滚点，并链接详报。最新哈希同步到登记簿，旧哈希保留在事件中。自本次起，PUA 条目的 `sha256_after` 表示共享字体当前基线，不表示该字形也在当日被重绘；实际修改次数以 `history` 和字形版本为准。
