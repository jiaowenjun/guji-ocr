# 445 页「使」字古文异体取字核验：𡷮与𠭆

核验与决策日期：2026-11-19。

**决策结果：康熙字典武英殿版第 445 页「使」条的第二个古文字，在本项目转写中采用 `𡷮`（U+21DEE）。当前大字字体已经收录 U+21DEE，因此不补录字体，也不分配 PUA。𡷮与𠭆有明确的文献关联，但没有足够依据把两个 Unicode 字符视为完全相同或在所有语境中通用互换；本次决定只适用于第 445 页这一处。**

当前转写见 [`kangxi-gold/annotations/0445.gj`](../../kangxi-gold/annotations/0445.gj)：

```gj
#使
古文：
#𡥐𡷮
```

机器可读核验记录见 [`evidence/page445-shi-variants/audit.json`](evidence/page445-shi-variants/audit.json)。本次没有修改任何字体文件；字体操作登记簿和字体补录 Changelog 因而不新增事件。

![445页使条第二古文字原始 SVG](evidence/page445-shi-variants/0445-06-K0000.svg)

## 1. 问题如何发现

445 页草稿由站点字头与 `guwen` 元数据辅助生成。「使」是该页第 4 个主字头，随后有两个 K0000 字头 SVG：

| 页内次序 | 站点记录 | 解释 |
| --- | --- | --- |
| 4 | `0445-04-00435-4F7F.svg` | 主字头「使」U+4F7F |
| 5 | `0445-05-K0000.svg` | 第一古文字，转写为𡥐 U+21950 |
| 6 | `0445-06-K0000.svg` | 本次争议的第二古文字 |

本地爬取库 `var/crawl/kangxi-crawl.sqlite3` 中，「使」条的站点结构化字段为：

```json
{"sword":"使","unicode":"U+4F7F","guwen":"𡥐、𠭆","wuying_edition":{"page":445,"nth_char":4}}
```

因此自动草稿最初把第二个古文字写成 `𠭆`（U+20B46），并附有“古文变体归并自站点 guwen 元数据，请对照原图核对”的提示。用户随后提出三个需要分开回答的问题：

1. `0445-06-K0000.svg` 是否能直接认定为 𠭆；
2. 大字字体是否已经存在该字或同一刻形；
3. 是否应把 SVG 补进大字字体。

这三个问题不能只凭站点 `guwen` 字符串或字体缺码分别作答；它们分别涉及底本字形、辞书考证、Unicode 字符身份和项目编辑策略。

## 2. 初次核验及其问题

初次核验取得了几项真实但不足以单独裁决的事实：

- 站点把 `0445-06-K0000.svg` 放在「使」条之后，并在 `guwen` 字段写成 𠭆；
- Unihan 18.0.0 把 U+20B46 与「使」U+4F7F 记为 `kSemanticVariant`；
- SVG 结构与字体中的 𠭆、𡷮都很接近；
- `guji-large.ttf` 没有 U+20B46。

据此一度作出“SVG 就是 U+20B46，应按 SVG 补录大字字体”的判断。这个结论过强，原因有三：

1. **站点元数据不是底本字形的最终码位裁决。** K0000 本身表示站点字头索引没有直接码位；`guwen` 是站点详情记录对古文字的归并结果，仍需与原图和辞书资料交叉核对。
2. **Unihan 的语义异体关系不能推出字形完全相同。** `kSemanticVariant` 说明字义或使用关系，不等于两个码位在任何文本中都可互换。
3. **字体缺码不能反推字符身份。** “大字字体不含 U+20B46”只回答覆盖问题；如果本页应选 U+21DEE，而字体已收该码位，就没有补字需求。

进一步对 `guji-large.ttf` 的 49,402 个非空 CJK 字形进行形状候选检索时，第一候选恰为 **𡷮 U+21DEE**，归一化 chamfer64 分数为 0.246；第二候选 𠭏 U+20B4F 为 0.478。这个结果提示需要调查 U+21DEE，但形状排名仍只是候选生成，不能代替文献判定。

## 3. 两个 Unicode 字符并不等同

本地 Unihan 18.0.0 与 CJKVI IDS 快照给出以下差异：

| 项目 | 𡷮 | 𠭆 |
| --- | --- | --- |
| Unicode | U+21DEE | U+20B46 |
| 区域 | CJK Unified Ideographs Extension B | CJK Unified Ideographs Extension B |
| `kRSUnicode` | 46.7（山部） | 29.7（又部） |
| `kTotalStrokes` | 10 | 9 |
| `kKangXi` | 0312.300 | 0101.070 |
| G Source | GKX-0312.30 | GHZ-10397.13 |
| IDS 快照 | `⿱山⿱⿱亠口又` | `⿱㞢𪠲`，另注 apparent=`⿱⿱㞢口又` |

两者有独立码位、不同部首笔画属性、不同康熙索引位置和不同来源标识。Unicode 数据没有把 U+21DEE 编码为 U+20B46 的别名；即使辞书将它们解释为讹变、异体或同一历史字形链上的成员，数字文本仍应保留码位差别。

Unihan 对「使」与 U+20B46 的记录是：

```text
U+4F7F  kSemanticVariant  U+20B46<kKangXi:T
U+20B46 kSemanticVariant  U+4F7F<kKangXi:TZ
```

这证明 U+20B46 与「使」有直接辞书关系，但不排除 U+21DEE 也在其他辞书传统中被收为「使」的异体，更不能据此把 U+21DEE 与 U+20B46 合并成一个 Unicode 字符。

## 4. 辞书资料及分歧

### 4.1 教育部《异体字字典》：𡷮作为「使」的异体

用户查阅台湾教育部《异体字字典》臺灣學術網路十四版（正式七版，2024），确认该辞书把 **𡷮 U+21DEE** 收为「使」的异体字。用户提供的考证摘要为：

- 《集韵》在「使」下收古字；
- 《四声篇海》把相关古字形写作𡷮；
- 《康熙字典》《汉语大字典》等继续收录这一形体。

这条资料为本页选择 U+21DEE 提供了直接的规范辞书依据。网站入口为 <https://dict.variants.moe.edu.tw/>。本次保存用户提供的查考结论，没有把该网站页面原文或页面快照复制入仓库；将来若要做可离线逐句复核，应另存具体条目 URL、版本页与访问日期。

### 4.2 《汉典》：𡷮被解释为𠭆的讹字

2026-11-19 直接读取《汉典》[𡷮条](https://www.zdic.net/hans/𡷮)，页面描述明确写作：

> 「𠭆」的讹字。

同一页面的《康熙字典》段落又引：

> 【集韻】使古作𠭆。註見人部六畫。

《汉典》[𠭆条](https://www.zdic.net/hans/𠭆)则把「事」和𡷮列入异体关联，并在《说文解字》段落中转录“𠭆，古文事”。这组资料恰好说明：𡷮、𠭆、「使」与「事」之间存在跨辞书、跨字书的复杂传承，不能把单条“异体”标签解释为无条件同码或全局替换关系。

### 4.3 《澳典》：𠭆与「事」的异体链

用户提供的《澳典》查考结果把 𠭆 列为「事」的异体字，并在相关异体字栏列出𡷮。网站入口为 <https://zidian.odict.net/>。该站在本次命令行复核时返回访问限制，因此文档将此项明确记为**用户提供的查考结果**，不冒充本次独立抓取的页面证据。

### 4.4 如何理解分歧

这些资料可以共同支持以下较窄而稳妥的认识：

- 𡷮与𠭆不是毫无关系的两个字；二者处在同一组古文字形、讹变和异体解释中；
- 𡷮有被规范辞书直接收为「使」异体的依据；
- 𠭆同时有“使古作𠭆”和“古文事”的文献路径；
- 辞书的“异体”“古文”“讹字”标签描述的是特定资料和传承关系，不自动授权现代数字文本跨语境统一替换。

## 5. 字体覆盖核验

2026-11-19 对仓库四份生产字体的 `best cmap` 实测如下：

| 字体 | U+21DEE 𡷮 | U+20B46 𠭆 | 结论 |
| --- | --- | --- | --- |
| `guji-large.ttf` | `uni21DEE` | 无 | 本页采用𡷮后，大字字体已有覆盖 |
| `guji-plane0.ttf` | 无 | 无 | 会继续回退到后续小字平面 |
| `guji-plane2.ttf` | `u21DEE` | `u20B46` | 两字均有宋体字形 |
| `guji-planef.ttf` | 无 | 无 | 与本次决定无直接影响 |

大字字体 SHA-256 为 `3973ccbe8bbdb4b91af44269a12f9b9f58daeb0c225d78e3a934f676f1c4c231`，与字体操作登记簿的现行基线一致。字体中除 `.notdef` 外没有未映射隐藏字形，因此 U+20B46 也没有以未映射字形名潜藏在大字字体中。

覆盖核验的作用是回答“采用这个码位后能否正常显示”。本次选择 U+21DEE 的主要依据仍是本页字形与辞书考证；字体恰好已有该字，只是让“不补录”成为直接结果，而不是决定字形身份的理由。

## 6. 决策依据与最终结果

本次按以下顺序裁决：

1. **底本和本页语境优先。** 目标是记录第 445 页「使」条列出的古文字，而不是建立𡷮／𠭆的全局规范化表。
2. **辞书考证优先于站点自动元数据。** 站点 `guwen=𡥐、𠭆` 是重要线索，但教育部《异体字字典》对𡷮的明确收录、用户对资料链的复核和 SVG 刻形共同支持本页取 U+21DEE。
3. **形状搜索只作旁证。** U+21DEE 是大字字体中的第一形似候选，说明这一选择与 SVG 轮廓相容，但 0.246 分不是字符身份的证明。
4. **字体覆盖最后考虑。** 选定 U+21DEE 后确认大字和小字后备字体均能显示，因而无须补字。

最终执行结果：

- `kangxi-gold/annotations/0445.gj` 使用 `#𡥐𡷮`；
- 不把 `0445-06-K0000.svg` 注入 U+20B46；
- 不修改 `guji-large.ttf`、系统字体或任何小字字体；
- 不分配 PUA；
- 不建立 `𡷮 → 𠭆`、`𠭆 → 𡷮` 或两者到「使／事」的全局替换规则；
- 其他页面、其他版本或其他语境遇到两字时，继续保留原始字形和 Unicode 码位，逐案核对。

## 7. 历史证据与当前状态的区分

`docs/research/evidence/2026-11-19-scan-blank-fix/p445-layout.json` 是原图空格识别修复任务生成的历史布局快照，其中仍可见旧转写 `𠭆`。该文件用于证明当时的空格定位和布局行为，不是本次异体字裁决后的当前金标，故不回写或静默改造。当前转写以 `kangxi-gold/annotations/0445.gj` 为准。

同理，站点数据库仍保留 `guwen=𡥐、𠭆`，因为它记录的是站点返回内容，不应为了迎合本项目编辑决定而篡改来源缓存。报告和新证据文件负责说明“来源怎么写”与“项目最后怎么取字”之间的差别。

## 8. 以后遇到同类问题的处理规则

1. 先保全原图、SVG、站点元数据和来源哈希，不直接用任一来源覆盖另一来源；
2. 将“视觉形似”“Unicode 属性”“辞书异体关系”“当前底本取字”“字体是否覆盖”分别记录；
3. K0000 的 `guwen` 映射只作为候选，不自动取得最终码位身份；
4. `kSemanticVariant`、辞书“古文／异体／讹字”均需注明来源和适用语境，不生成无条件替换表；
5. 先决定本页应使用的标准码位，再检查字体覆盖；不能从字体有无倒推字符身份；
6. 字体已有选定码位时不重复补录；确实缺字时才进入字体补录流程，并单独登记哈希、来源和回滚点；
7. 修订金标时保留原标签、修改理由和证据边界，历史任务证据保持快照语义。

## 9. 复核范围与限制

- 本次直接复核了本地站点数据库、目标 SVG、Unihan 18.0.0、CJKVI IDS 快照、四份生产字体和《汉典》当前页面。
- 教育部《异体字字典》和《澳典》的具体条目结论来自用户本次查考；已记录网站、版本说明和结论，但未保存页面快照，不能仅凭本报告复现网页逐字内容。
- 形状候选检索按 bbox 归一化后计算 chamfer64；它会弱化比例、笔势和部件来源差异，只适合发现候选。
- 本报告决定的是本项目 445 页转写，不试图解决𡷮、𠭆、「使」和「事」在全部历史字书中的总关系。
