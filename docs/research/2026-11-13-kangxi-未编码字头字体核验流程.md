# 未编码字头（K0000）字体核验流程：0334-04 首例缺字判定

核查日期：2026-11-13。对象为康熙字典网站爬取库（`datasets/kangxi-crawl.sqlite3`）中 site 334 页第 4 个字头 `0334-04-K0000.svg`。本次完整执行：下载缩略图 SVG（1 次 HTTP）、栅格化、对本地康熙字典體 KX_47043_14 全库 49,407 cmap 字形做对称 chamfer 初筛、下载 Unihan.zip 做字典槽位仲裁、GlyphWiki 参考字形目视终验、cmap 覆盖判定。机器可读证据与哈希见 [evidence/2026-11-13-kangxi-unencoded-0334-04-fontcheck.json](evidence/2026-11-13-kangxi-unencoded-0334-04-fontcheck.json)。

两个最重要的结论：其一，该字真实身份为 **U+2BD6E 𫵮（CJK Ext-C，kKangXi 0079.090）**，**不在本地康熙字典體中**——这是首例「字体缺字」（此前 95 项评估 92 存在、2 疑似、1 残损，零缺字）；其二，**kKangXi 槽位仲裁比字形匹配更决定性**——全库 chamfer 第一名 U+20077 𠁷（0.731，落在同字阈值内）实为 classic 下一页的形近邻字，纯字形排序会误判。

## 1. 背景与数据基础

### 1.1 K0000 机制（摘自 2026-11-12 网站调研与 95 项评估）

- 字头缩略图文件名规则：4 段 `{页}-{序}-{流水号}-{码位hex}.svg`（编码字头）、3 段 `{页}-{序}-K####.svg`（站内 K 编号，**K0000 为占位号无身份**）、2 段 `{页}-{序}.svg`（同序号编码字头的原书扫描孪生，非新字符）。
- 阅读页中未编码字头的链接实体破损（`sword=&#x` 后无十六进制值）——「未编码」是站方索引缺口，不代表字在 Unicode 之外；95 项评估证实其身份均在已编码区（Ext-B 59 / BMP 33）。
- 站方口径「47043 字头全支持」指其 webfont；本地同源字体 `~/Library/Fonts/KX_47043_14.ttf`（傳承版 v001.014，2023-03-02）cmap 共 49,407 = BMP 24,858 + Ext-B 24,548 + Ext-G 1（U+317AB），**PUA 零覆盖、Ext-C 零覆盖**。

### 1.2 本案对象

```sql
SELECT ord, page_seq, entry_no, k_code, codepoint, char, svg
FROM page_chars WHERE page = 334 ORDER BY ord;
-- 0|1|00052||20014|丮|0000s/0334-01-00052-4E2E.svg
-- 1|2|00053||20015|丯|0000s/0334-02-00053-4E2F.svg
-- 2|3|00054||20016|丰|0000s/0334-03-00054-4E30.svg
-- 3|4||K0000|||0000s/0334-04-K0000.svg          ← 本案
-- 4|5|00055||20017|丱|0000s/0334-05-00055-4E31.svg
```

注：`page_chars.codepoint` 存十进制整数（20014 = U+4E2E），svg 文件名内为十六进制。

### 2.4 chamfer 全库初筛（辅助证据，不能单独定字）

对字体全部 cmap 字形渲染后与目标做对称 chamfer（scipy EDT）。要点与标尺沿用 95 项评估：

- 阈值标尺：**< 0.785 同字**（锚点：𠁧 同字异版对 = 0.785 上限）、0.8–1.0 疑似、> 1.0 异字；128px 画布、按 bbox 居中归一化。
- numpy uint8 matmul 在 256 处回绕，重叠计数必须用布尔与 + 计数。
- 49k 字形一轮约 1–2 分钟（PIL 112px 渲染 + EDT）。

核心代码（完整可复用版见 evidence JSON 附录同款）：

```python
def norm_ink(img):                      # 二值化→bbox 裁切→128×128 居中
    a = np.asarray(img.convert("L")) < 128
    ys, xs = np.nonzero(a); sub = a[ys.min():ys.max()+1, xs.min():xs.max()+1]
    ...                                  # 等比缩放至 ≤120px 后居中贴布

def chamfer(a, b):                       # 对称平均 EDT，单位 px@128
    ea = ndimage.distance_transform_edt(~a); eb = ndimage.distance_transform_edt(~b)
    return 0.5 * (ea[b].mean() + eb[a].mean())
```

**定位**：只用来产生候选与排除（断档优势 > 0.15 时有较强提示），**不可作为身份结论**——见 §4 邻字陷阱。

### 2.5 kKangXi 槽位仲裁（决定性）

```bash
curl -sS -O https://www.unicode.org/Public/UCD/latest/ucd/Unihan.zip
unzip -o -q Unihan.zip -d unihan
grep -P "^U+\S+\tkKangXi\t0079\.090\b" unihan/Unihan_DictionaryIndices.txt
# → U+2BD6E  kKangXi  0079.090   （全库唯一占主）
```

- **槽位格式** `pppp.ccc`：`pppp` = classic 康熙页码；`ccc` = 列×100 + 位×10（.010=左栏位1，…，.100=左栏位10，.110=右栏位1），可带第 4 位重出后缀（.021/.061/.111）。
- **锚定方法（比页码偏移可靠）**：取同页已知字头的 kKangXi，K0000 的槽位应落在其构成的连续区间内。本案：丮 .060 / 丯 .070 / 丰 .080 / **[空洞 .090]** / 丱 .100 —— 唯一空洞即目标槽位；Unihan 中唯一占主 U+2BD6E 且 **G 源 GKX-0079.09 直录该槽**（GKX = 康熙字典 G 源，身份即书目事实，与字形无关）。
- **名册连续性双向验证**：前页（336 页 = classic 80 槽 8–右 1：丵 .080 / 𠁰 .090 / 𠁱 .100 / 𠁴 .110）与后向（串 0080.020、丳 0080.040、临 4E34 0080.071）均连续吻合。
- site 页 ≈ classic 半栏（约 5 个槽位一组），**不要用整页偏移换算**，分组边界会漂移。
- **Unihan 数据质量坑**：若干 GHZ 字 kKangXi 重复（本地 grep 证实 U+20075/20076/20077 同报 0080.111），遇到重复槽位值时以「名册区间 + 唯一占主」裁决。

### 2.6 GlyphWiki 参考字形终验

本地字体缺字时（§2.7 判不在），字形终验改用 GlyphWiki：

- 页面 `https://glyphwiki.org/wiki/u{小写hex}`；本案 `u2bd6e` 的别名即 **kx-0079009 / kx-007909**（康熙槽位直录字形）与 extd-02374，独立印证 §2.5。
- 图片直链 `https://glyphwiki.org/glyph/u2bd6e.100px.png` ✓；`@7.svg` 变体会截断、`-g.100px.png` 变体 404。WebFetch 对 glyphwiki.org 返回 403，用 webReader 或 curl。
- 本案字形 = ⿰U+21D00×2（左右同部件并排），与扫描字头目视吻合（产物 `0334-04-K0000-verdict.png`）。zdic 对 G 源孤字无页面（404），勿依赖。

### 2.7 字体覆盖判定

```python
from fontTools.ttLib import TTFont
cmap = TTFont("/Users/jwj/Library/Fonts/KX_47043_14.ttf").getBestCmap()
print(0x2BD6E in cmap)   # → False
```

分区速判：本地字体 = BMP + Ext-B + Ext-G(1 字)。**身份落在 Ext-C/E/F 等 SIP 其他平面区段时必然缺字**，不必再渲染比对（无字形的 chamfer 是无效值，本案 8.534 即空白画布噪声）。

## 4. 陷阱清单

| 陷阱 | 现象 | 规避 |
| --- | --- | --- |
| `/v2/kxzt/` 直链 | 200 + 1.6MB HTML（任何 Referer 都一样） | 用 `www`/`p` 主机的 `/kxzt/`；检查文件头 `<?xml` |
| chamfer 邻字 | 𠁷(0.731) 赢过真身——同部首近页形近字（classic 80 页，紧随本案槽位之后） | chamfer 只当初筛；槽位仲裁定案（同 331 页 𠁧/𠁦 之辨一类） |
| Unihan 重复槽位 | U+20075/20076/20077 同报 kKangXi 0080.111 | 名册区间 + 唯一占主裁决；grep 本地 Unihan 而非网页转述 |
| 视觉模型独判 | 两次目视结论相反（先猜 竝/幷，后误选 𤛙 U+246D9） | 仅做终验比对（同/否），不做开放识别 |
| 缺字时的 chamfer | 目标不在字体 → 真身无得分，榜单全为噪声 | 先 cmap 分区速判（§2.7），缺字走 GlyphWiki 终验 |
| GlyphWiki URL 变体 | `@7.svg` 截断、`-g` 变体 404、WebFetch 403 | 用 `glyph/uXXXX.100px.png` + curl/webReader |
| numpy uint8 回绕 | 256 处溢出致重叠计数错误 | 布尔与 + `sum()` |

## 5. 全景更新与影响

- 评估全景（96 项 = 原 95 + 本案）：**92 在库 + 2 疑似（2345-02→昙、2856-02→过）+ 1 残损（4673-12）+ 1 缺字（0334-04→U+2BD6E）**。
- 「站方 47043 字头全支持」口径需修正：K0000 字头站方索引本就无码位，其 webfont 同样不含；本地缺字与站方行为一致。
- 缺字显示兜底：引入含 Ext-C 的外部字体（如 BabelStone Han），或用 GlyphWiki SVG 按孪生机制内嵌。
- 爬取推进中：截至本文 K0000 已 118 个、未编码（含 2 段名孪生）共 123 项，均待按本流程核验。

## 6. 后续 K0000 核验决策树

1. 2 段名孪生 → 跳过（非新字符）。
2. 同页已知字头 kKangXi 锚定槽位 → Unihan grep 槽位唯一占主且 G 源 GKX 匹配 → **身份定**。
3. cmap 分区速判：BMP/Ext-B → 大概率在库（补 `page_chars.codepoint` 即可）；Ext-C 及以外 → **记缺字清单**，GlyphWiki 取参考字形终验。
4. 槽位空洞无占主（名册缺口）→ 退回 chamfer 候选 + GlyphWiki 字形 + 视觉比对，标记低置信。
5. 存量复核：原 2 项疑似与 50 项低区分度身份可用槽位法重裁（如 0331-04 𠁧/𠁦 之辨——𠁧 的 kKangXi 为 0080.030，与 site 331 页槽位区间的相容性值得复查）。
