# kangxizidian.com 阅读页结构调研：字头索引与全书抓取可行性

核查日期：2026-11-12。入口为 [阅读页 `/v2/index2.php?page=313`](https://www.kangxizidian.com/v2/index2.php?page=313)。本次先后两轮：先抓取 2 个阅读页原始 HTML（0313、0330）、对整页 JPG 与字头 SVG 各做 1 次 HEAD、下载 2 个字头 SVG 检查内容，并用 kangxi-gold 的人工转写（`guji-preview/src/samples/kangxi-yibu.gj`）交叉验证了 0313 页的字头身份；随后循字头缩略图链接追查到**字头详情页**，抓取 3 个详情页样本（丁、丂、𠆤）并与人工金标逐字符比对。**没有抓取全书页面，没有运行任何 OCR**；原始样本哈希、214 部首映射全表与逐项观察见[证据](evidence/2026-11-12-kangxizidian-site-structure.json)。

两个最重要的发现：其一，阅读页中列的**字头缩略图文件名编码了页码、页内序、全典字头流水号与 Unicode 码位**，等于一份现成的「页 → 字头」索引，且每页内嵌 214 部首 → 起始页映射；其二，**字头详情页以纯 Unicode 文本提供完整释文**（第 7 节）——这推翻了本报告初稿及此前调研「站点无纯文本、逐字 SVG 渲染」的判断，kangxi-gold 扩页可改用站点全文作预标注底稿。

## 1. URL 体系

| 对象 | 模板 | 说明 |
| --- | --- | --- |
| 阅读页（本次对象） | `/v2/index2.php?page={N}` | 整页扫描 + 字头缩略图 + 目录，N 为 1–7738 |
| 大图页 | `/v2/index.php?page={N}` | 另一变体，本次未解析其结构差异 |
| 整页扫描图 | `https://p.kangxizidian.com/kangxi2/{N:04d}.jpg` | 直链完全规则；即 WD-2T `kangxizidian-wuyingdian` 与 kangxi-gold 的图片来源（已在[图片证据](evidence/2026-11-12-kangxi-gold-images.json)核查） |
| 字头缩略图 | `https://www.kangxizidian.com/kxzt/{N}000s/{…}.svg` | **目录按千位分桶**（N=页码千位，如 1075 页在 `1000s/`）；命名规则见第 3 节 |

## 2. 阅读页三列结构

一张 `width=1280` 的表格，三列：

```
├─ 左列（弹性）   整页扫描图 <img class="center-fit" src="…kangxi2/NNNN.jpg">
├─ 中列 width=96  本页字头缩略图（每字一表：链接 + 72px SVG）
└─ 右列 width=510 翻页表单 + 大图页入口 + 附编目录 + 214 部首索引 + Google AdSense
```

- 缩略图链接形如 `<a href='index2.php?page=313&sword=丁'><img src='../kxzt/0000s/….svg'>`，`sword` 参数可反查字所在页。
- 右列导航给出最前(1)/上一(N−1)/下一(N+1)/最後(7738)与 GET 跳页表单（`page`，`maxLength=4`，7738 恰为 4 位）。
- 附编页码表：御製序 8、纂修 32、凡例 38、總目 54、檢字 86、辨似 152、等韻 190、正文一部起 312、補遺 7414、備考 7564。

## 3. 字头缩略图：命名规则与索引价值

文件名有两种形态：

| 形态 | 模板 | 示例 |
| --- | --- | --- |
| 有 Unicode 码 | `{页:04d}-{页内序:02d}-{全典流水号:05d}-{unicode_hex}.svg` | `0313-01-00002-4E01.svg` = 丁（U+4E01），流水号 00002 |
| 站方未映射 | `{页:04d}-{页内序:02d}-K{站内号:04d}.svg` | `0313-02-K0000.svg` = 𠆤（U+201A4，丁古文） |

- **全典流水号跨页连续、只计主字头**：00001 为 p312 的「一」，丁为 00002；p330（丨部起始页）四个字头 丨丩𠁡个 连续编号 00045–00048。古文等未映射字记 K 码且不占流水号。此为 2 页样本推断，未全书验证。
- **K 码 ≠ 无 Unicode**：0313 的 K0000 实为 Ext-B 的 𠆤（U+201A4），说明站方索引未覆盖该码位；K 码清单可作为「站方视角长尾字」素材，但码位身份需另行核实。
- 两种形态对应可区分的视觉样式：有码字缩略图底色 `#DABA94`，K 码字为 `#FEF2E3`；K 码字的 `sword` 链接为破损实体 `&#x`。
- SVG 本体是 128×128 的字形 path（ImBatch 批量生成），**不含页内坐标**——能拿到「页 → 字头清单」，拿不到字在扫描图上的 bbox。

**与 kangxi-gold 的交叉验证**：0313 页站点中列恰有两个字头（丁 00002、K0000），与 `.gj` 人工转写的字头块（`#丁古文` 之后 `#𠆤【唐韻】…` 独立成块）数量、顺序一一对应。这支持「缩略图列 = 该页全部字头（含古文变体）」的读法。

## 4. 214 部首 → 起始页映射

每页右列内嵌完整部首索引（01 畫「一」=312 … 17 畫「龠」=7372），从 0313 单页解析即得全部 214 项（全表在证据 JSON）。价值：

- 直接生成分部抓取清单（kangxi-gold 现有 312–328 正是「一部」起点）；
- 与《康熙字典》214 部首体系数量吻合，可作为流水号/页码推断的锚点。

## 5. HTML 怪癖与解析建议

- UTF-8 **带 BOM**：用 `utf-8-sig` 读或先剥离。
- 文档非合法 XHTML：`<body>` 出现在 `<head>` 内、属性大量无引号（`width=1280`、`src=https://…jpg`）、存在破损实体 `&#x`。
- 缩略图文件名 4 段/3 段两种形态需分别匹配；翻页链接混用 `index2.php?page=N` 与 `?page=N` 两种相对形式。
- 建议用宽容解析（lxml html / html5ever）或分段正则；本次用正则完成全部提取，样本哈希固定于证据文件。
- 抓取礼仪沿用 kangxi-gold 下载脚本的约定（robots 已核查全允许，≥1.2s 间隔 + 抖动）。

## 6. 对 guji-ocr 的可用路径

1. **页 → 字头索引（全书）**：遍历 7738 个阅读页解析中列，可得每页字头的页内序、全典流水号、Unicode/K 码。约 7.7k 次小 HTML 请求（每页约 13KB），按既有限速约 3 小时内完成。用途：扩页时的页选择、字头顺序与归属页的机器校验、K 码长尾字清单。
2. **全文释文可从详情页获取**（更正，同日）：本节初稿曾断言「缩略图列只有字头、站点无纯文本、扩页仍需人工转写」——**该结论已被第 7 节推翻**：`/search/index_v.php?stype=Word&sword={字}&detail=y` 提供完整释文纯文本。扩页流程可改为「站点全文 → 预标注底稿 → 人工校对」，人工从转写降为校对；仍需自校的理由见第 7.4 节（PUA 字形、站点校勘差异未经逐条审计）。
3. **bbox 需另行获取**：SVG 无页内坐标，行/字坐标仍按既定路线由 OCR 对齐半自动补充。
4. **校验既有金标**：可先用 312–328 这 17 页跑一遍解析，与 `.gj` 字头块对照，作为解析器的验收集再扩展到全书。

## 7. 字头详情页：全文纯文本源（同日补充核查）

### 7.1 发现路径与端点

阅读页缩略图链接 `index2.php?page=N&sword=丁` 打开的页面本身仍是扫描图 + 缩略图，但其中以 **iframe** 嵌入真正的数据页：

```html
<iframe src="/search/index_v.php?stype=Word&sword=丁&detail=y" ...>
```

即详情端点为 `/search/index_v.php?stype=Word&sword={URL 编码字头}&detail=y`，服务端渲染纯 HTML、无 JS 依赖（每字约 10–25KB）。DOM 结构：`字頭：X` 标题在 `#cornerbody3`，卡片本体在 `#cornerbody1`。页面尾部另有被注释掉的静态 URL 变体 `/search/stype-Word-{字}-y-1.html`（全文版）与 `stype-Word-{字}-n-1.html`（字頭版），本次未启用。

### 7.2 卡片内容（全部纯文本，两处冗余存储）

| 类别 | 字段 | 备注 |
| --- | --- | --- |
| 字头 | 字头、古文（如 丁 → 𠆤） | 古文字形直接给出 Unicode 字符 |
| 元数据 | 部首、部首筆畫、部外筆畫、總筆畫、拼音（可多个）、注音（可多个）、倉頡、统一碼 | 拼音/注音各带反查链接 |
| 版本定位 | 卷別〈子集上〉、**同文書局本：N頁，第X字**、**武英殿本：N頁，第X字** | 双版本页位映射，附 `/v1/`、`/v2/` 链接 |
| 释文 | 完整释文 | `og:description` meta 一份 + 正文 HTML 一份；正文引书名带 `<span class=rcornertext>`、字头字带红字 `<font>` 标记，结构化程度高于 meta |

### 7.3 保真度：与人工金标逐字符一致

用 difflib 将站点释文（剥离 PUA 与空白后）与 kangxi-gold 人工转写比对：

| 条目 | 站点净字符 | 金标净字符 | 相似比 | 差异 |
| --- | ---: | ---: | ---: | --- |
| 丁（966 字长条） | 958 | 966 | 0.9958 | 仅金标自身的页界标记 `@314`/`@315`，正文零差异 |
| 丂（49 字短条） | 49 | 49 | 1.0000 | 无 |

样本量 2 条（一长一短），不足以断言全书无校勘差异，但足以证明该文本源与武英殿扫描底本是同源严肃转写，非机器粗糙 OCR。

### 7.4 爬取注意

- **PUA 字符**：释文含 U+EAB1 段落分隔符（丁条 32 处），剥离即可；站方 kxfont 以私用区承载无 Unicode 字形，其他条目是否混入 PUA 字形字符需在批量抓取时抽样统计（发现即须人工定字）。
- **可查性边界**：`sword` 参数须传 Unicode 可表示字符；缩略图链接为破损实体 `&#x` 的真·未编码字无法经此端点查询（丁古文 𠆤 属 Ext-B 已编码，可查且返回独立条目「【集韻】丁古作𠆤。註詳一部一畫。」）。
- **侧栏小部件勿爬**：大圖頁右侧 `歡迎光臨／古今人名／康熙頻道` 等同名 `#cornerbody1` 块中，「古今人名」经同页两次抓取证实为**服务端随机轮换**（人名列表完全不同），与页面内容无关。
- **批量路径**：解析 7738 页缩略图列得全字头表（含流水号）→ 逐字取详情 ≈ 4.7 万请求；沿用既有限速（≥1.2s+抖动）约 2 天可完成全书。
