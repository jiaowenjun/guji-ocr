# kangxizidian.com 阅读页结构调研：字头索引与全书抓取可行性

核查日期：2026-11-12。入口为 [阅读页 `/v2/index2.php?page=313`](https://www.kangxizidian.com/v2/index2.php?page=313)。本次抓取 2 个阅读页原始 HTML（0313、0330）、对整页 JPG 与字头 SVG 各做 1 次 HEAD、下载 2 个字头 SVG 检查内容，并用 kangxi-gold 的人工转写（`guji-preview/src/samples/kangxi-yibu.gj`）交叉验证了 0313 页的字头身份。**没有抓取全书页面，没有运行任何 OCR**；原始样本哈希、214 部首映射全表与逐项观察见[证据](evidence/2026-11-12-kangxizidian-site-structure.json)。

最重要的发现是：阅读页中列的**字头缩略图文件名编码了页码、页内序、全典字头流水号与 Unicode 码位**，等于一份现成的「页 → 字头」索引；每页还内嵌 214 部首 → 起始页映射。这为 kangxi-gold 扩页提供了页选择与字头级校验的依据，但不改变此前结论——站点没有可抓取的纯注文文本。

## 2. 阅读页三列结构

一张 `width=1280` 的表格，三列：

```
├─ 左列（弹性）   整页扫描图 <img class="center-fit" src="…kangxi2/NNNN.jpg">
├─ 中列 width=96  本页字头缩略图（每字一表：链接 + 72px SVG）
└─ 右列 width=510 翻页表单 + 大图页入口 + 附编目录 + 214 部首索引 + Google AdSense
```

- 缩略图链接形如 `<a href='index2.php?page=313&sword=丁'><img src='../kxzt/0000s/….svg'>`，`sword` 参数可反查字所在页。
- 右列导航给出最前(1)/上一(N−1)/下一(N+1)/最後(7738)与 GET 跳页表单（`page`，`maxLength=4`，7738 恰为 4 位）。
- 附编页码表：御製序 8、纂修 32、凡例 38、總目 54、檢字 86、辨似 152、等韻 190、正文一部起 312、補遺 7414、備考 7564。

## 3. 字头缩略图：命名规则与索引价值

文件名有两种形态：

| 形态 | 模板 | 示例 |
| --- | --- | --- |
| 有 Unicode 码 | `{页:04d}-{页内序:02d}-{全典流水号:05d}-{unicode_hex}.svg` | `0313-01-00002-4E01.svg` = 丁（U+4E01），流水号 00002 |
| 站方未映射 | `{页:04d}-{页内序:02d}-K{站内号:04d}.svg` | `0313-02-K0000.svg` = 𠆤（U+201A4，丁古文） |

- **全典流水号跨页连续、只计主字头**：00001 为 p312 的「一」，丁为 00002；p330（丨部起始页）四个字头 丨丩𠁡个 连续编号 00045–00048。古文等未映射字记 K 码且不占流水号。此为 2 页样本推断，未全书验证。
- **K 码 ≠ 无 Unicode**：0313 的 K0000 实为 Ext-B 的 𠆤（U+201A4），说明站方索引未覆盖该码位；K 码清单可作为「站方视角长尾字」素材，但码位身份需另行核实。
- 两种形态对应可区分的视觉样式：有码字缩略图底色 `#DABA94`，K 码字为 `#FEF2E3`；K 码字的 `sword` 链接为破损实体 `&#x`。
- SVG 本体是 128×128 的字形 path（ImBatch 批量生成），**不含页内坐标**——能拿到「页 → 字头清单」，拿不到字在扫描图上的 bbox。

**与 kangxi-gold 的交叉验证**：0313 页站点中列恰有两个字头（丁 00002、K0000），与 `.gj` 人工转写的字头块（`#丁古文` 之后 `#𠆤【唐韻】…` 独立成块）数量、顺序一一对应。这支持「缩略图列 = 该页全部字头（含古文变体）」的读法。

## 4. 214 部首 → 起始页映射

每页右列内嵌完整部首索引（01 畫「一」=312 … 17 畫「龠」=7372），从 0313 单页解析即得全部 214 项（全表在证据 JSON）。价值：

- 与《康熙字典》214 部首体系数量吻合，可作为流水号/页码推断的锚点。

## 5. HTML 怪癖与解析建议

- UTF-8 **带 BOM**：用 `utf-8-sig` 读或先剥离。
- 文档非合法 XHTML：`<body>` 出现在 `<head>` 内、属性大量无引号（`width=1280`、`src=https://…jpg`）、存在破损实体 `&#x`。
- 缩略图文件名 4 段/3 段两种形态需分别匹配；翻页链接混用 `index2.php?page=N` 与 `?page=N` 两种相对形式。
- 建议用宽容解析（lxml html / html5ever）或分段正则；本次用正则完成全部提取，样本哈希固定于证据文件。
- 抓取礼仪沿用 kangxi-gold 下载脚本的约定（robots 已核查全允许，≥1.2s 间隔 + 抖动）。

## 6. 对 guji-ocr 的可用路径

1. **页 → 字头索引（全书）**：遍历 7738 个阅读页解析中列，可得每页字头的页内序、全典流水号、Unicode/K 码。约 7.7k 次小 HTML 请求（每页约 13KB），按既有限速约 3 小时内完成。用途：扩页时的页选择、字头顺序与归属页的机器校验、K 码长尾字清单。
2. **不能替代注文转写**：缩略图列只有字头，不含释文；「kangxizidian.com 无纯文本」的既有结论不变，扩页仍需人工转写或 OCR 预标注。
3. **bbox 需另行获取**：SVG 无页内坐标，行/字坐标仍按既定路线由 OCR 对齐半自动补充。
4. **校验既有金标**：可先用 312–328 这 17 页跑一遍解析，与 `.gj` 字头块对照，作为解析器的验收集再扩展到全书。
