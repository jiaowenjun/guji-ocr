# 歹部「歺」旁刻形的码位核验：〈歺㐱〉（殄）在小字字体中的存在性

核查日期：2026-11-14。机器可读证据与产物哈希见 [evidence/2026-11-14-kangxi-ea-form-codepoints.json](evidence/2026-11-14-kangxi-ea-form-codepoints.json)。kKangXi 槽位仲裁法沿用 [未编码字头字体核验流程](2026-11-13-kangxi-未编码字头字体核验流程.md) §2.5。

## 1. 背景与问题

标注 @344（kangxi-gold/annotations/0344.gj:23-25）时遇到字头 𠂈 的注文：

```
#(增)𠂈
【說文】古文殄
字。註詳歺部
```

用户提供的刻本裁图显示「殄」位置的字左旁刻作「歺」（歹省左上短撇），提问：**〈歺㐱〉这个字在小字字体中是否存在？** 此问实际分两层——码位层（Unicode 有无此字的专码、小字字体 cmap 是否覆盖）与字形层（渲染出的左旁是歺还是歹）。另涉正文里已有的「歺」单字（0344.gj:25「註詳歺部」）。

小字字体栈见 guji-preview-grid/src/matrix.css:127 与 src/index.css:14-42：正文小字依次回退 GujiPlane0（中华书局宋体00平面，BMP）→ GujiPlane2（02平面，Ext-B）→ GujiPlaneF（15平面，Ext-F）；字头大字体为 GujiLarge（康熙傳承版 KX_47043_14 + 补录）。

## 2. 结论

1. **〈歺㐱〉没有 Unicode 专码，它就是殄 U+6B84 的康熙刻形。** kKangXi 槽位 0579.450（classic 579 页右栏位 5）由 U+6B84 唯一占主，无 .451 重出变体；CHISE IDS 全库（Basic + Ext-B，共 37,379 条）检索 `⿰歺㐱` 零命中，`⿰X㐱` 全表仅 殄=⿰歹㐱 一条 歹 族记录。
2. **小字字体里存在、不缺字，但字形是标准「歹」旁。** U+6B84 ∈ GujiPlane0 cmap（渲染左上带短撇的规范 歹 旁）；U+6B7A 歺 ∈ GujiPlane0 且为真歺形——0344.gj:25「註詳歺部」照写无虞。GujiLarge 的 U+6B84 同样渲染歹旁：康熙傳承版不做共用码位的字形变体，其歺形全部体现在 Ext-B 专码上。
3. **歹部专码规律（对将来标注 site ~2766+ 页面通用）**：康熙 歹部（classic 578–580）名册中，G 源把每个字头条目识别为唯一 Unicode 字——能识别的落标准码位（殃 6B83@.410、殄 6B84@.450、殅 6B85@.540、殆 6B86@580.040、徂 6B82@.340），**无法与既有字等同的歺旁刻形条目有 Ext-B 专码 U+239B5–U+239F7（67 字，⿰歺X 系）**，且与 ⿰歹X 系并列成对（如 ⿰歺人 U+239B8 vs ⿰歹人 U+239B9；康熙另立 ⿰歺徂 U+23A16@581.140 与 徂 U+6B82 并存）。字体覆盖：**GujiPlane2 全覆盖 67/67**（正文小字无缺字之忧）；GujiLarge 62/67，缺 U+239BE/239D7/239D8/239EF/239F1 五字（将来字头核验的候选）；GujiPlane0/PlaneF 对该区段零覆盖（BMP/Ext-F 分区使然，属正常）。
4. **不建议给 U+6B84 补录歺形字形**（[字体补录流程](2026-11-13-kangxi-字体补录流程.md) 的方案 A）：共用常用码位，改动会波及所有标准「殄」的显示。字形级保真只能留给 .gj 部件描述记法（〈歺㐱〉这类写法）——即 gj 语法糖评估中「未实现」的部分。

> 边界说明：classic 579.450 处刻本的左旁形态本次未独立核对扫描原件（依用户裁图与部件判读为歺旁；视觉模型对有无左上短撇的判读不稳定，见 §4）。该不确定性不影响结论——无论刻形是歺是歹，可用的码位都只有 U+6B84。

## 3. 核验过程

### 3.1 身份仲裁：kKangXi 槽位名册

```bash
curl -sS -O https://www.unicode.org/Public/UCD/latest/ucd/Unihan.zip
unzip -o -q Unihan.zip -d var/unihan
grep -P "kKangXi\t05(78|79|80)\." var/unihan/Unihan_DictionaryIndices.txt
```

歹部名册（节选，完整表见 evidence JSON）：BMP 标准码位与 Ext-B 专码**按槽交错**——.150 歹 6B79、.170 𣦵 239B5、.180 歺 6B7A、.190 𣦶 239B6、.200 𣦷 239B7、.210 㱙 3C59、.220 死 6B7B、.340 徂 6B82、.410 殃 6B83、**.450 殄 6B84（唯一占主）**、.480 𣧠 239E0、.540 殅 6B85……证明康熙原书两种旁形并存成独立条目、G 源逐一识别，而非整体字形替换。

### 3.2 CHISE IDS 排除专码

```bash
# github.com/chise/ids 镜像：IDS-UCS-Basic.txt + Ext-B-1/-2
grep -h "⿰歺" IDS-UCS-*.txt   # 18 条 ⿰歺X，无 ⿰歺㐱
grep -h "㐱"  IDS-UCS-*.txt | grep ⿰   # ⿰X㐱 全表 23 条，歹族仅 殄=⿰歹㐱
```

⿰歺X 系专码遍布 歹部（⿰歺⺃ 239B7、⿰歺人 239B8、⿰歺又 239BC、⿰歺夭 239D5、⿰歺古 239EE、⿰歺合 23A04、⿰歺徂 23A16、⿰歺魚 23A55……）也见于他部（⿰歺女 216DD、⿰歺帶心 22905）——歺旁刻形的编码是全书性现象，非 歹部 特例。

### 3.3 站方映射印证（爬取库）

var/crawl/kangxi-crawl.sqlite3 `page_chars` 中 site 2766 页（歹部 起始）名册与 Unihan 槽位逐一吻合：13150 歹 6B79@.150、13151 𣦵 239B5@.170、13152 歺 6B7A@.180、13153 𣦶 239B6@.190、13154 𣦷 239B7@.200、13155 㱙 3C59@.210。殄 所在槽位（site ~2767–2769）尚未爬到（全书慢速爬取进行中），但站方映射与 Unihan 的一致性已在可见段建立。

### 3.4 字体 cmap 覆盖

fontTools `getBestCmap()` 实测（脚本 var/unihan/check_fonts.py）：

| 码位 | large | plane0 | plane2 | planef |
| --- | --- | --- | --- | --- |
| U+6B7A 歺 | ✓ | ✓ | — | — |
| U+6B84 殄 | ✓ | ✓ | — | — |
| 歹部专码区 239B5–239F7（67 字） | 62 | 0 | **67** | 0 |

（cmap 总数：large 49,408 = 49,407 + 补录 U+2BD6E；plane0 30,706；plane2 61,228；planef 42,620。）

### 3.5 字形判读：chamfer 裁决

U+6B84 的左旁形态在 plane0/GujiLarge 中是歺是歹，视觉判读出现**两次矛盾**（整表判 large=歹、plane0=歹；放大判读 plane0=歺），小字号下左上短撇的分辨不可靠。改用与 [95 项评估](2026-11-13-kangxi-未编码字头字体核验流程.md) 同源的 chamfer，且**参照取同字体自身的 Ext-B ⿰歺X/⿰歹X 左旁**（⿰歺人 239B8、⿰歺又 239BC vs ⿰歹人 239B9、⿰歹力 239BA），等高缩放消除纵横比失真：

| 字体 | 殄 左旁 vs ⿰歺X 参照 | vs ⿰歹X 参照 | 判定 |
| --- | --- | --- | --- |
| guji-large（参照同字体） | 2.14 | **1.30** | 歹旁 |
| plane0（参照取 plane2 同族） | 2.56 | **1.95** | 歹旁 |
| 对照组：歺 U+6B7A | **1.76 / 2.33** | 3.38 / 2.71 | 歺旁 ✓（sanity 通过） |

结论：两个字体的 U+6B84 均为标准歹旁。康熙傳承版不给共用码位做歺形变体，其 歹部 歺形全部在 239xx 专码上——与 §3.3 站方映射互证。

## 4. 方法论坑

- **视觉模型判读 歺/歹 不可靠**：差异仅左上一笔短撇，84px 渲染两次判读矛盾；chamfer（同字体、同形类参照）是可靠裁决手段。早前用「殄左旁 vs 独立 歹/歺 整字」直接比对也失真（1.3–4.5 的无效值区间）——参照必须同为左部件且等比缩放。
- **chamfer sanity check 的一个反例**：独立字 歹 U+6B79 反而比 歺 更贴近 ⿰歺X 参照（1.94 vs 2.18）——独体字与压缩部件的宽高比差异压过了笔画差。所幸 歺 对照组 margin 达 2 倍、殄 判定 margin 明确，且三条独立证据（整表目视、放大目视、chamfer）中两两一致的结论收敛于歹旁。
- Ext-B 的 CHISE IDS 文件行首格式是 `U-000239xx` 而非 `U+239xx`，grep 时注意（Basic 文件才是 `U+` 格式）。
- `python3 -I` 隔离模式读不到用户 site-packages（fontTools/PIL/scipy 装在用户级），自写脚本用默认模式即可，但仍避免在被检数据目录内运行。

## 5. 对后续标注的规范建议

1. .gj 中 殄 一律写 U+6B84（如 0344.gj:24 现状），预览呈歹旁属码位层天花板，非缺字；不要为它造 PUA 或补字。
2. 「註詳歺部」类引部的 歺 用 U+6B7A，plane0 有真歺形。
3. 将来标注 歹部 页面：字头凡有 239xx 专码者直接用专码（站方 SVG 文件名即含 hex 码位，page_chars.codepoint 十进制）；五个 guji-large 缺字（239BE/239D7/239D8/239EF/239F1）届时按 K0000 流程核验、必要时走补录；正文小字引用这些形时 plane2 全覆盖，无需处理。
4. 歺旁保真需求（若将来提出）应走 .gj 部件描述语法扩展，不动画体文件。
