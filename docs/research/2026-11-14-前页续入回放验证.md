# 前页续入（continuation_from_prev）回放验证

日期：2026-11-14
测试基准：kangxi-gold 初校 24 页（@312–328、@330–336，status=first；@312/@330 前页缺档不计分，实评 22 页）
证据数据：[evidence/2026-11-14-continuation-replay.json](evidence/2026-11-14-continuation-replay.json)
评估工具：[scripts/eval_continuation_replay.py](../../scripts/eval_continuation_replay.py)（本次入库，可回归复跑；`--json` 出证据、默认人读报告）
姊妹报告：`eval_ocr_trim.py`（同题独立回放，结论一致；本文与其互补的口径差异见 §5）

## 1. 问题

`add --page N` 的前页续入链路（`continuation_from_prev` → `ocr_trim_continuation`）此前只在零散页上 dry-run 过，从未以人工初校为基准做过逐页量化。本测试用全部已初校页回放该链路，回答三个问题：

1. 宿主定位（含纯延续页跨页回溯）是否选对字头？
2. 断点（前页已放置文本在库文中的末端）是否与人工初校一致？
3. OCR 页界裁剪的末端差多少字？

## 2. 方法

- **回放口径**：对每个初校页 N（前页 N−1 在数据集内），以**初校版** (N−1).gj 为输入重放 `continuation_from_prev`——比生产链更严苛：生产输入是机器草稿（与库文同源、锚定近乎精确匹配），初校版带人工校订噪声，容差对齐必须真正工作。
- **GT**：初校 N.gj 首个字头行之前的正文 = 人工放置在本页物理范围内的续文。**提取按行不按空行带**——初校字头行独占一行但不必独占一带（482b91b 批量格式化后 @313–328 与 @331+ 格式混用），按带提取会把行内 `#字头` 之后的下词条正文误计入 GT（本测试早期版本曾因此污染 16 页，见 §4 轨迹）。
- **指标**（全部按 `_norm` 归一化）：
  - `cover` = LCP(cont, GT)/len(GT)：未裁剪的库内余段应把 GT 整体作为前缀覆盖（断点起点保真）；
  - `端差` = trim 末端与 GT 末端的字数差：取 difflib 匹配块末块在**两侧**的映射端点计算——容忍库文与图的零散异文。不能用 LCP 度量末端：1 字异文就会截断（「中」链 895 字库文与图仅差 5 字，LCP 口径曾假判 cover 0.25）。
- **评分**：10 = 逐字一致或范围正确（末端对齐）；9/8/7 = 末端差 1–2/3–5/6–10 字；5/3 = 11–20/20+ 字；漏续入 = 1；误宿主 = 2；正确跳过 = 10。

## 4. 会话轨迹：1.55 → 2.73 → 5.55 → 9.14 → 9.55

每一步爬升都有明确归因（证据文件 `score_trajectory_during_session` 有完整记录）：

| 均分 | 触发变化 | 归属 |
|---|---|---|
| 1.55 | 初态：活库缺 312–327 字头详情（老管线页从未入库）＋ stub 变体词条（𠁩 等 10 字「玉篇古文…字註詳」）抢宿主 | 数据缺口 ×16 页、算法缺陷 ×1 |
| 2.73 | `fetch_kangxi_entry.py --pages 312-327` 补 36 字头入**活库**（此前仅有 /tmp 副本） | 本测试补数据 |
| 5.55 | 工具修复 11bfa68（host_in 变体链状态机：词条末变体行 `#𠁚、#𠙐`、独占变体行、竖排「古/文」拆行；古文剥离容忍 `：`、`、`）＋ 本测试修 GT 提取 bug（按行不按带） | 并行会话修复 ×6 页、评估自纠 ×16 页 |
| 9.14 | 评估度量修正（SM 末块端差替代 LCP——中链 895 字仅 5 字异文被 LCP 假判） | 评估自纠 |
| 9.55 | `ocr_page_cut` 末段判信（末窗 30 字密度 ≥0.5 且连续收尾 ≥2 才信，否则从块尾回缩/拒裁；@331 −50、@324 −6） | 并行会话修复，随本报告一并提交 |

教训有二：**评估器本身要先被怀疑**——GT 提取与度量口径的两个 bug 曾分别造成 16 页、4 页的假失败；**「库内转写 vs 图」的零散异文是常态**，任何逐字比较的口径都必须走容差对齐。

## 5. 与 eval_ocr_trim.py 的关系

`eval_ocr_trim.py`（并行会话）与本文同题独立回放，结论一致（初校格式三处击穿已修、@331/@324 过裁、±1 边界差可接受）。本文的互补口径：GT 按行提取（其按首字头行前的正文带，本文实测按带会把行内字头后正文误入 GT——两脚本对 313–328 的 GT 定义需对齐时以按行为准）；端差用 SM 末块两侧映射（LDP/LCP 口径受零散异文干扰）。新发现为其所无：@335 丱条库文缺按语段（数据天花板）；活库字头补齐（此前仅 /tmp 副本）。

## 6. 结论与遗留

**结论：前页续入链路在 22 个初校页上 19 页满分、2 页 ±1–2 字边界差、1 页数据天花板——算法侧无遗留失败。** 宿主定位（含跨页回溯、变体链、两种字头格式）、断点、OCR 页界裁剪三个环节均达到或以 1–2 字逼近人工初校。

遗留（均非算法失败）：

1. **@335 类库文缺段**：站点转写与图有实质差异时（丱条缺 44 字按语），续入只能放站点文本，人工改写即初校工作流本身。无算法解。
2. **生产隐患（未修，暂无实害）**：`cmd_add` 只补本页字头详情，前页宿主字头缺详情时续入**静默跳过**——老管线页（312–328）的直接后继会踩（本次已补齐活库故无实害）。建议：续入 skip 原因为「无详情」时对 page−1 触发一次 `fetch_kangxi_entry` 后重试。
3. 数据缺口 @329/@337 缺档（跳页添加所致），@312/@330 因此不可评，非算法问题。
