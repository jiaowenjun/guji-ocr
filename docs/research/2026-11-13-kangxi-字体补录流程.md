# 康熙字典體字体补录流程：K0000 缺字字形入库

撰写日期：2026-11-13（首例 U+2BD6E 补录当日）。本文是**补录操作手册**：什么场景补、怎么补、怎么验证、怎么回滚。字头身份如何判定（kKangXi 槽位仲裁等）见姊妹篇 [未编码字头字体核验流程](2026-11-13-kangxi-未编码字头字体核验流程.md)，本文只管「身份已知后把字形写进字体」。实现已固化为 [scripts/kangxi_font_patch.py](../../scripts/kangxi_font_patch.py)。

## 1. 适用场景与字体资产

### 1.1 什么时候需要补录

康熙字典网站的未编码字头（K0000）中，身份落在**本地康熙字典體不覆盖的 Unicode 区段**（Ext-C/E/F 等 SIP 平面；该字体仅 BMP 24,858 + Ext-B 24,548 + Ext-G 1，Ext-C 零覆盖）时，应用内显示退化为中华书局宋体（plane2 兜底）或系统字体，与康熙原刻风格不统一——此时以站方字头缩略图 SVG 为字形源补录。身份已在字体 cmap 内的 K0000 无需补录（站方索引缺口而已）。

### 1.2 应用字体栈与补录边界（截至本文）

| 文件（`guji-preview-grid/public/fonts/`） | 身份 | 与补录的关系 |
| --- | --- | --- |
| `guji-large.ttf`（46.7MB） | KangXi Font Full Version v001.014（= 系统 `~/Library/Fonts/KX_47043_14.ttf`，两者原为字节级同源） | **补录目标**。`.large` 大字视图与 `index.css:204` 主栈的第一优先 |
| `guji-plane0/2/f.ttf` | 中华书局宋体三平面（plane2 已含 Ext-C 4,149 字） | **未补录**。`.small` 小字矩阵栈（`GujiPlane0→2→F`）由此渲染，补录后小字视图该字仍为宋体风格——如需统一按同流程跑 plane2 |
| `~/Library/Fonts/KX_47043_14.ttf` | 系统侧同源字体 | 同步补录对象（金标校对等本机场景），改后需重启应用 |

## 2. 原理

### 2.1 字形源：站方缩略图 SVG

- 直链 `https://p.kangxizidian.com/kxzt/{千位桶}/{文件名}.svg`（**带 `/v2/` 前缀会返回 200 + 1.6MB HTML**，必须检查文件头 `<?xml`）。
- 所有缩略图同管线生成（autotrace）：`viewBox 0 0 128 128`，路径在 **1280 坐标系 y 向上**，外层统一 `<g transform="translate(0,128) scale(0.1,-0.1)">`。
- 轮廓为 nonzero 填充的扫描剪影：无封闭计白的字（如首例 2 条外轮廓）零缠绕风险；**含「口」类部件的字有孔洞轮廓**（autotrace 反向缠绕，TrueType nonzero 同语义兼容），靠验证闸逐字把关。

### 2.2 基线校准（关键）

SVG 路径空间与字体 units（upem 1024）的比例不能想当然（≠1024/1280）。用**同页已知邻字**做锚：该字在字体 cmap 内的字形 bbox × 其 SVG 路径 bbox，解出统一仿射 `x_f = s·x_p + tx, y_f = s·y_p + ty`（x/y 各算 scale 取均值；路径空间 y 已向上，无需翻转）。首例实测 s=0.8739，用第二邻字交叉验证误差 ≤17 单位（1.7% em）。

### 2.3 轮廓转换与表注入

```
svgLib.parse_path(d) → TransformPen(仿射) → Cu2QuPen(max_err=1.0@1024em,
reverse_direction=True) → TTGlyphPen → Glyph.recalcBounds(glyf)
```

注入五处：`glyf.glyphs[name]`、`glyphOrder`、`maxp.numGlyphs`、`hmtx`（advance 取 anchor 字形=1024；该字体 numberOfHMetrics 为每字形一组）、`cmap` 全部 **format-12 子表**（增补平面码位只有 (3,10) 等格式装得下，format-4 不动）。字体自带的 GSUB/GDEF/GPOS 不引用新字形，落默认类，无害。写字形后用 `os.replace` 原子替换。

### 2.4 验证闸

`rsvg-convert` 栅格化源 SVG vs `PIL` 渲染补录字形（200px），bbox 归一化到 128×128 后对称 chamfer（EDT 均值，px）：**< 0.15 通过**。标尺依据：首例实测 0.029，基线「丰 扫描 vs 原字体原生渲染」0.035（同轮廓传递与原生字形同量级），阈值留 4 倍余量；若触发（孔洞缠绕错误、校准漂移会显著抬高）则拒绝写入。

## 3. 操作手册

### 3.1 前置条件

- Python 3.9+：fontTools≥4.60（svgLib）、PIL、numpy、scipy；`rsvg-convert`（Homebrew）供验证闸。
- 已按核验流程确定身份码位，且确认 `cp not in font cmap`。
- 字形源 SVG 与同页邻字 SVG 已下载到 `datasets/kangxi-unencoded/svg/`。
- 改系统字体前备份：`cp -p ~/Library/Fonts/KX_47043_14.ttf ~/.kx-font-backup/…-orig.ttf`（目录勿放 ~/Library/Fonts 内，避免被 fontd 当新字体注册）。

### 3.2 标准命令

```bash
python3 scripts/kangxi_font_patch.py \
  --font guji-preview-grid/public/fonts/guji-large.ttf \
  --font "$HOME/Library/Fonts/KX_47043_14.ttf" \
  --svg        datasets/kangxi-unencoded/svg/{页}-{序}-K0000.svg  --cp {十六进制码位} \
  --anchor-svg datasets/kangxi-unencoded/svg/{同页邻字}.svg      --anchor-cp {邻字码位}
```

- `--font` 可重复（仓库字体与系统字体一次跑完）；`--gate` 默认 0.15。
- 成功输出每份字体的 chamfer 与体积变化，并追加流水日志 `datasets/kangxi-unencoded/font-patches.jsonl`（码位、校准参数、bbox、advance、验证分、前后字节数）。
- 验证闸失败会**拒绝替换**并保留原字体，按 §5 坑清单排查。

### 3.3 收尾

1. **缓存戳递增**：`guji-preview-grid/src/index.css` 的 GujiLarge `url("/fonts/guji-large.ttf?v=…")` 改新版本串（当前 `001015-2bd6e`），否则浏览器可能用缓存的旧字体。Safari 注意：url() 必须保持在 src 首位（历史坑，加查询串不影响）。
2. 系统字体更新后**重启相关应用**（CoreText 按进程缓存）。
3. 效果预览：仿照 `/tmp/kx_check/demo/`（@font-face 三联对比 + 字典语境行），或直接在 guji-preview-grid 内查该页。
4. 提交时注意：46MB 二进制每次补录都是新 blob 入 git 历史。频繁补录可攒批一次提交，或未来转 LFS。

## 5. 坑清单

| 坑 | 现象 | 规避 |
| --- | --- | --- |
| 验证脚本反相误判 | 扫描图白底占比大，`mean>128 → 反相` 把背景当墨迹，chamfer 出垃圾值 2.9 | 栅格本来就是黑墨白底，直接 `<128` 阈值，**不要做均值反相判断** |
| SVG 直链陷阱 | `/v2/kxzt/…` 返回 200 + HTML | 用 `p.` 或 `www.` 主机的 `/kxzt/`；查文件头 |
| 校准想当然 | 误用 1024/1280=0.8，字整体偏小 9% | 必须同页邻字 anchor 校准 |
| 孔洞缠绕 | 含「口」部件的字若轮廓方向异常，孔洞填实 → chamfer 抬升 | 验证闸拒绝写入即为信号；逐字过闸，勿批量免检 |
| head/xMin 缺失 | TTGlyphPen 产出的 Glyph 无 xMin 属性 | `glyph.recalcBounds(glyf)` 后再取 |
| 两份字体 sha 不一致 | 同源输入分别补录后 sha 不同（3 字节头部校验和区差异） | 无功能影响（表数据一致、渲染一致），以验证闸与渲染为准 |
| 浏览器缓存 | 字体 URL 不变时旧字形"阴魂不散" | `?v=` 缓存戳随每次补录递增 |
| 系统字体不刷新 | 替换 `~/Library/Fonts` 后应用仍显旧字形 | 重启应用 |
| 备份位置 | 备份放 Fonts 目录会被 fontd 注册成重复字体 | 备份放 `~/.kx-font-backup/` |

## 6. 回滚

- **仓库字体**：`git restore guji-preview-grid/public/fonts/guji-large.ttf`（每次补录前状态在 git 历史里），并把 index.css 缓存戳改回。
- **系统字体**：`cp ~/.kx-font-backup/KX_47043_14-v001014-orig.ttf ~/Library/Fonts/KX_47043_14.ttf`，重启应用。
- 单字形逻辑回滚暂无（重打包剔除该字形），如遇字形质量问题优先重新校准重打而非回滚整字体。

## 7. 后续展望
