## 如何解读

- **文件哈希固定所读内容。** 远程 `main` 会变化；哈希用于核对版本，不保证页面永久保留。JSON 本身未附全部原始大文件或图片，不能单凭它重跑全套检查。
- **计数有明确单位。** 记录数、非空 OCR 行数、图像路径数和不同内容哈希数分别统计，不能互换为独立金标页数。
- **文件事实与质量结论分开。** 找到重复或两个错漏样例，能证明这些局部情况存在，不能据此推出全库错误比例或学术不端。
- **源文件代码问题与实际使用分开。** 11 页 notebook 的窄 Unicode 清洗和按字节大小配对存在风险，但没有证据证明微信作者的 dots 测试使用了同样流程。
- **许可记录按对象区分。** 代码许可证不能自动覆盖数据、权重、影像或输出；保存的许可哈希只对应当时读取版本。
