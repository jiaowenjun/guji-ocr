# 康熙字典两套扫描图的页号对应规则

> 制定日期：2026-11-18（原始扫描入库当日）。规则经六个内容锚点实证 + 两批互不重复的
> 随机 100 张图像验证（合计 200 页、195 张可验页全部命中、0 反例），互查工具
> [`tools/crawl/kangxi_page_map.py`](../tools/crawl/kangxi_page_map.py)。

## 规则速查

```
站点页 N（1–7738） →  原始扫描第 ⌈N/2⌉ 开；N 奇数 = 右半页（_R，先读），N 偶数 = 左半页（_L，后读）
反向：原始图（卷 v 第 p 开的 h 半，h∈{L,R}） →  站点页 = 2×K − (h==R ? 1 : 0)，K 为该开的全局开序
```

例：站点 `2000.jpg` → 开 1000 → 卯集局部第 107 开 → 偶数取左半 → `04.卯集/04_0107_L.jpg`
（该页首字头「扔」，与站点页字头索引一致）。

## 一、两套资源

| | 爬取图 `pages/` | 原始图 `pages_original/` |
| --- | --- | --- |
| 路径 | WD-2T `raw/kangxizidian/pages/NNNN.jpg` | WD-2T `raw/kangxizidian/pages_original/<卷目录>/vv_pppp[_L\|_R].jpg` |
| 来源 | kangxizidian.com 阅读页原图（`p.kangxizidian.com/kangxi2/NNNN.jpg`） | 第三方整本扫描（13.4G zip 已入库存证） |
| 编号 | 站点页 ID 1–7738（全书固定，爬虫进度不影响编号语义） | 卷目录 00.总目→13.补遗 + 卷内开号 + 可选 `_L`/`_R` 半页后缀 |
| 数量 | 随爬取增长 | 7658 张 = 80 张无后缀 plain + 3789 对 `_L`/`_R` |
| 质量 | 带页脚两行水印；**经各向异性挤压**（内容区长宽比同源但整体 h/w≈1.37 vs 原始≈1.75） | 无水印，版框完整，上下留白可达 10–20% |

两套图**同版同源**（同一版本印本的同源扫描，字头内容逐字对应），仅处理链不同。因此任何
以内容为依据的用途（OCR、校对底图、版式分析）都应优先用 `pages_original`，站点图只在需要
与站点数据对齐时使用。

**版本页号语义**：站点页 ID = 词条「武英殿本」页号（`entries.record_json` 的
`wuying_edition.page`，全书严格相等）。词条另有「同文書局本」页号（`tongwen_edition`，
石印本，全书仅约 1631 页），是另一套版本的页码，**与这两套图的编号均不对应，勿混用**。

总量守恒：3869 开 × 2 = **7738**，与站点导航「最後頁」分毫不差；站点页区间与爬虫库
`page_chars` 推出的各卷首字页区间全部吻合（子集上 312、丑集上 794、寅集上 1310、卯集上
1796、……亥集上 6865、補遺丑集 7424、備考 7566+）。

### 2.2 正向：站点页 → 原始图

1. `K = ⌈N/2⌉`（全局开序，1 基）；
2. N 为奇数 → 该开 `_R` 半页（中式古籍**右半先读**）；N 为偶数 → `_L` 半页；
3. 该开若为 plain（无 `_L`/`_R`），两个站点页都映射到该单图（见 §三）。

### 2.3 反向：原始图 → 站点页

卷内局部开号 p 换全局开序 `K = 卷起点 + p − 1`（起点查 §2.1 表），则

- `_R` 半页 → 站点页 `2K − 1`（奇数）；
- `_L` 半页 → 站点页 `2K`（偶数）；
- plain → 该文件承载站点页 `2K` 或 `2K−1` 之一的面（见 §三），另一面仅存在于站点。

### 2.4 plain 文件的位置（结构锚）

每卷 plain 的位置固定，是分卷/子卷边界的结构标记：

| 卷 | plain 开号 | 含义（已目视核验） |
| --- | --- | --- |
| 各集（01–12） | 0001 | 卷首书衣（带馆藏号/色卡，如 `01_0001.jpg`） |
| 各集（01–12） | 上/中分卷处一对（如子集 0045+0046） | 子卷边界**空白护页**对（无文字；位置恰落在上下子卷字头空档内，如子集上末页 382 与子集中首页 400 之间） |
| 各集（01–12） | 中/下分卷处一对（如子集 0124+0125） | 同上，中→下边界空白护页对 |
| 各集（01–12） | 最末开（如子集 0242） | 卷末叶 |
| 00.总目 | 0001、0091、0092、0150 | 卷首 + 目录区空白护页对（`00_0091` 已核为空白护页）+ 卷末 |
| 13.补遗 | 0001、0073、0074、0178 | 卷首 + 補遺/備考之间空白护页对（`13_0073` 已核为空白护页；对应站点 7527–7530，落在補遺末页 7512 与備考首页 7566 之间的空档）+ 卷末 |

## 三、plain 开的两面语义

plain 开同样占**两个**站点页号（算术守恒要求，且已被卷区间锚点证实），但本地只存一面。
站点在两个页号上展示该叶的**两个不同面**：

- `01_0001.jpg`（子集卷首书衣，带馆藏号与色卡）= 站点 **302**（偶，左面）；
- 站点 **301**（奇，右面）= 同开**御製扉页**（龙纹书名牌），此面本地缺失、仅站点有。

因此对 plain 开：能确定的是「这一开对应哪两个站点页号」；哪一号对着本地文件，
按内容判断（多数情况本地文件是卷首书衣面 = 偶数页；个别需目视确认）。

## 四、边界与例外

- **无字头区**：每集卷首约 5–7 开（封面/序/目录）、卷尾数开，以及补遗卷 補遺→備考 之间
  约 26 开，站点页无字头索引；这些页仍严格服从编号规则（多处分卷首字页锚点钉死）。
- **近空白页**：少数页面无文字或仅版框（如站点 6846、305、187、2218；个别原始图同），
  灰度 std < 12，无法做内容验证，规则对其仅为算术成立。
- **爬取进度**：`pages/` 尚未爬全（慢速礼貌爬取中）；对应关系是**编号语义**，与某张图
  是否已下载无关。原始图侧 7738 个页号已全覆盖。
- **站点图不可直接像素比对**：非等比挤压 + 水印，直接缩放/投影/配准全部失效；须先按
  版框归一（内容区长宽比 ≈1.39）再同画布比对，验证方法见 §五。

## 五、验证记录（2026-11-18）

1. **算术守恒**：3869×2=7738，各卷开数与站点区间互洽。
2. **内容锚点**（字头级目视核对）：

| 站点页 | 内容 | 原始图 |
| --- | --- | --- |

| 1040 | 丑集中·土部扉页 | 02_0128_L |
| 1462 | 寅集中·山部扉页 | 03_0081_L |

| 7713/7714 | 備考香部尾页 / 馬部起始 | 13_0166_R / 13_0166_L |

3. **两批随机抽样**（seed 20261118 / 20261119，互不重复，合计 200 页、页号 13–7580）：
   自动比对（版框归一 + Pearson + ±2 开邻页阴性对照，阈值 0.45/边距 0.06）+
   低分仲裁（整页拼图目视；争议例以 `page_chars` 字头序列与反切对库定案）。
   结果：**195/195 可验页全部命中，0 反例**；5 页近空白跳过。4 例目视异议均被
   数据库铁证推翻（如 4879：预测页首字头「芑」= 站点字头索引首字）。

## 六、工具与常用配方

互查工具（仅标准库，`--verify` 含锚点回归）：

```bash
python3 tools/crawl/kangxi_page_map.py 2000                     # 站点页 → 原始图路径
python3 tools/crawl/kangxi_page_map.py --to-site 04.卯集 0107 R # 反向查询（→ 1999）
python3 tools/crawl/kangxi_page_map.py --table                  # 7738 行全表 CSV
python3 tools/crawl/kangxi_page_map.py --verify                 # 结构 + 锚点校验
```

典型任务：

- **给 OCR/校对换无水印底图**：对任一站点页 N 取 `site_to_original(N)`，直接替换
  `pages/NNNN.jpg`，不受爬取进度限制。
- **从原始图定位站点数据**（字头索引、词条全文）：`original_to_site()` 得站点页号，
  再查 `var/crawl/kangxi-crawl.sqlite3` 的 `page_chars` / `entries`。
- **批量映射**：`--table` 导出 CSV 供脚本消费。
