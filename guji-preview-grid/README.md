# guji-preview-grid

以 **CSS Grid 字格矩阵**重构古籍刻本渲染层的 Web 应用。原姊妹项目 guji-preview
（flex 流式渲染移植版）已于 2026-11-14 删除，本项目为唯一的预览与校对应用。

## 与原 flex 流式版的设计差异

| | flex 流式版（旧，已删除） | 矩阵版（本项目） |
|---|---|---|
| 布局模型 | 流式：`row-reverse` flex，行对齐由内容"涌现" | 严格矩阵：布局引擎推导 1em 字格坐标，显式 grid 轨道 |
| 跨行书名 | `book-start/middle/end` 三态 + 负边距阶梯 + `:has()` 按边删 border 拼接 | 同列连续片段合并为**单个跨行矩形项**（单一边框）；仅 wrap 连接边开口 |
| 行线贯通 | 无（仅外框） | 大行之间界栏全页高（1px 伪元素 + subgrid 占满行，可开关） |
| 渲染管线 | `parsePages → React 组件`（旧版，项目已删除） | 主路径 `gj2ir → layout3（骨架布局）→ overlay 装饰 → 矩阵组件`（[Guji IR v3](../docs/design/guji-ir.md) 双层结构；原 Flex 对照视图已于 2026-11-14 移除） |

解析器与 CodeMirror 编辑器共用 `.gj/2` 行内词法；旧 PageModel 接口由 IR 适配。应用外壳自
2026-11-12 起移除独立「编辑」双栏模式，打开即数据集对照视图。

## 架构

```
.gj → gj2ir（转写骨架、overlay、源码映射）
    → applyBookLayout（数据集选择书籍版式，写入几何快照）
    → layout3（profile 清洗 → BandPlan → 字格坐标、rawRanges、版式诊断）
    → indexLayout + projectBooks（按全局 span 投影书名）
    → MatrixPages（按版式配置裁剪、显示诊断、光标联动）
IR → irToText（同一 profile 的阅读序 TXT）
```

单页编辑时每次文本更新只解析一次，布局、书名框及光标／点击联动共用当前 IR，
不再使用实时高亮与防抖布局两份快照。字符映射统一为 `rawRanges`，保留清洗的
展开／收缩区间；预览溢出定位、重叠诊断和 OCR 导出共用 `getItemBounds` 占格几何。
书名框只作装饰覆盖，鼠标点击穿透到下方大列。

`DatasetView` 管理数据加载、保存与顶栏；`DatasetWorkspace` 持有光标与三栏尺寸状态，
光标移动不更新数据集顶栏。双击字格或单击大列背景通过 `GujiEditorHandle.revealPosition()` 每次
执行定位、折叠选区、滚动和聚焦，不用数值状态表示命令，因此重复点击相同位置仍然有效。

`PagePaper` 统一负责每页的页码、警告汇总、背景、纸边和字格尺寸变量；矩阵组件只负责
版框、字格、装饰与高亮。缩放仍按原图高度适配，原图和纸面共用比例，保留原有纸边、
纸面最小高度及 1px 版框计算。`MatrixBand` 只接收本列高亮并使用 `memo`：在 @312
的 8 大列实测中，同列光标移动从执行全部 8 列缩小到 1 列，跨列为前后 2 列；
解析、布局和编辑器组件均未重新执行，其余缓存继续交给 React Compiler。

通用结构固定每大列两小列。书籍版式的三个参数为 `bandsPerPage`、
`largeCellsPerBand`、`smallRowsPerLargeCell`；武英殿版参数及扫描边距统一保存在
[`kangxi-gold/dataset-config.json`](../kangxi-gold/dataset-config.json)。高度比 1:2 派生
2×2 小格，高度比 1:1 派生 2×1 小格；小格不要求是正方形。

`gj2ir` 只解析文本；布局前显式调用 `applyBookLayout(doc, config.layout)`。
结果保存 `meta.layout` v1 数值快照和 `meta.layoutPreset` 标识/修订号；特殊页配置
`layout.pages[页码]`，解析为页级快照。`layout3` 不猜书籍、不查询预设注册表。
旧康熙 JSON 用 `importLegacyKangxiDocument` 显式补齐，已有自定义几何保持原样；
未知数据集缺配置时报错。完整契约与扩展示例见 [版式分层](../docs/design/guji-ir.md#10-书籍版式与通用结构分层2026-11-17)。

`.gj/2` 的缩进空位直接写入骨架；旧语法 JSON 需从迁移后的 `.gj` 重新生成。`irPageToText(page, profile)` 必须显式传入
文档 profile，避免丢失清洗规则；清洗输出同时保留原始码点区间，支持归一化展开／收缩。

版式诊断检查页宽、列数、意外多小列、空列、重叠和溢出；页面出现告警时页码旁显示
⚠，悬停查看原因。诊断保留原始内容，不自动合并分段。当前武英殿版每页固定显示 8 大列 × 12 大格，
正文不足时左侧和底部自动留白，无需填充空列；少于 8 列不告警。超出 24 小格的文字
向下隐藏，超出 8 大列版框的内容向左隐藏；底部红线和左边缘红色箭头提示溢出，悬停可查看原因。
正文、书名框和高亮始终使用相同的固定字格，校对改动不会因超宽而挤窄字格。


## 已知偏差与兼容性

- **Safari 本机字体匹配**：WebKit 对这批用户字体（康熙傳承版/中华书局宋体）的
  `local()` 会「解析成功但渲染不可用」（伪命中，还会挡住 src 后续来源），font-family
  写注册名也不匹配；Chrome 一切正常。修复：`@font-face` 以 **url() 为首源**加载随仓库
  入库的 `public/fonts/*.ttf`（guji-large 45M = kangxizidian.com 康熙傳承版；
  guji-plane0/2/f 18M+41M+25M = 中华书局宋体 00/02/15 平面，版权归原发行方，限研究用途），
  任何浏览器与服务器部署渲染一致；`local()` 名字链退居其次仅作文件缺失时的 Chrome 兜底。
  Playwright WebKit 像素级验证：url 优先渲染真字形，local 优先渲染回退 serif。
  编辑器 `.cm-scroller` 字体栈同样接入三平面（拉丁/符号仍等宽），扩展 B/C 区字符不再缺字
- **亚格居中**：小字组比 band 窄奇数格时整体偏移半格，复刻居中位置。
- **跨行／跨页书名**：保持转写行界，书名按全局 span 顺序投影并在页缝开口；
  行 ID 作为不透明引用使用，不再依赖 `pXXXX-bN-lM` 的拼写。
- **subgrid**：需 Chrome 117+ / Safari 16+ / Firefox 71+（2023 起 baseline）；
  导出的独立 HTML 同样依赖

## 功能

- **编辑器 ↔ 渲染列联动**：光标所在**大行**琥珀高亮（间隙取前行）；光标落在
  **书名区间**内时两侧书名框同时点亮（含跨大行 wrap，如【史記·儒/林傳】）；
  双击渲染字格 → 编辑器光标定位到源码中对应字符之后、滚动并聚焦，对应字符点亮。
  支持大小字、书名框内文字、扩展区汉字及 `*` 空位；圈注合字按整格定位到首个源字符之后。
  字格单击不移动光标，避免双击前跳到列首；单击列内背景仍定位到该列首个产出字符之后。
  定位基于 IR 骨架 `src` 与
  overlay（`src/ir/linkage.ts`）；骨架独立性契约见 ir.spec（v3 验收套件）
- 打开即**数据集对照**视图（原「编辑」双栏模式、Flex 对照视图均已移除）：
  kangxi-gold 金标三列可视化与校对（见下节），含界栏开关
- **字格开关**：按当前页版式画满整页；武英殿版为 8 大列 × 12 大字格，
  每大格内 2×2 小格。高度比 1:1 时为 2×1，内部只有竖向虚线；
  大格边线 1px 实线、小格分隔 1px 虚线，空列和短列的空白处也画满。版框尺寸与开关无关，
  内容不足时靠右、靠上排列；格线在所有文字、装饰与高亮之下，不占布局空间。
  格线直接锚定正文 Grid 轨道，避免 Safari 对背景平铺尺寸取整造成累计偏移。
  超宽异常页按固定字格向左溢出并裁切，原始内容仍保留在编辑器，溢出标记随校对结果更新。
- **亮/暗主题**：默认跟随系统（`prefers-color-scheme`），顶栏可手动三态切换
  （跟随系统/浅色/深色，localStorage 持久化）；语法高亮配色经 CSS 变量随主题切换，
  刻本纸面与扫描图保持原色不反色

## 数据集对照模式

数据集模式为三列布局：**扫描原图 | 刻本渲染 | .gj 编辑器**，
用于目视核对 [kangxi-gold](../kangxi-gold/README.md) 金标与后续扩页校对：

- 渲染列内容与原图**版框**像素级对齐：每页独立纸层，纸边和背景来自数据集扫描配置，
  `unit = (版框宽−2px)/横向字格数`；默认 **界栏关 + 原图高度适配视口**，
  原图和渲染共用缩放比例，面板宽度不足时沿用各自滚动区的溢出处理。
- ←/→ 翻页（编辑器聚焦时不劫持）；未保存修改按页保留，切页/切模式不丢
- **「添加新页」**：输入页码（1–7738）→ `tools/dataset/kangxi_page_tool.py` 补数据（含**前页未完字头续入**：
  解析前页 .gj 尾部，在库内该字头全量释义中容差对齐定位断点，余段作为本页
  草稿开头——跨页书名靠 per-page 语义边界自然衔接：前页下开口、本页上开口；
  **OCR 辅助删头去尾 + 折行**：本地 paddleocr-baseline 服务运行时，续文按该页扫描图
  的 OCR 识别范围自动裁剪到页面物理末界（文本仍以库内转写为准，OCR 只作范围
  标尺），并按 OCR 行组在草稿大行内插入折行换行（只插入换行不改字符；全量测试
  21 页折行界 96.2% ±0）；服务未运行/对齐不可信时回退未裁剪未折行的平铺草稿
  （sqlite `var/crawl/kangxi-crawl.sqlite3` 已有则零联网，缺则由 fetch_kangxi_page/
  fetch_kangxi_entry 增量爬取）→ 由 page_chars + entries 生成 .gj 草稿（字头行 +
  释义段落带，未编码字 `#□` 占位注释）入 `annotations/`、manifest 追加该页，
  前端通过 `dataset-index` 重新读取当前清单并自动跳转；`POST /dataset/page-tool` 中间件仅 dev 生效
- **来源卡片拆分**：添加新页按字头、宿主页位和 SVG 选择来源卡片，排除有其他卡片佐证的附带子段，避免「仆」混入「僕」等释文。旧缓存利用已存 HTML 按需解析，无须重抓；归属不明时保留原文并提示待核。已有校对文件不会自动重写，规则及验收见[来源卡片拆分说明](../docs/development/kangxi-source-cards.md)。
- **爬取字头与详情**：字头栏通过 `POST /dataset/page-tool` 的
  `{ action: "crawl-heads", page }` 按页只读查询 SQLite；点击字头后通过
  `{ action: "crawl-entry", codepoint }`（十进制 Unicode 码位）只取该字词条。
  切页/重开弹窗读取当前数据库，不再生成或读取 `page-heads.json`、`entries.json`，
  添加新页也无需同步爬取快照。查询不会联网补抓或创建数据库；未采集、查询失败
  与已采集但零字头分别显示，失败可重试。爬取库须在本机可用。
- **页标签**：草稿（爬取生成）/ 初校 / 精校，存 manifest.json 每页 `status` 字段，
  工具条徽章与页清单均带标记；既有 17 页定为初校
- 「保存回数据集」写回 `kangxi-gold/annotations/NNNN.gj`（仅 dev server 生效的
  `POST /dataset/save` 中间件，vite.config.ts；校验页码在库内且首行仍为 @页码）
- 保存只写 `.gj`；评测和校验从 manifest 指定的 `.gj` 实时派生 IR/TXT。
  需要导出快照时才运行 `npx -y tsx kangxi-gold/scripts/build_annotations.ts`，不会改写源文件或 manifest。
- **OCR 查询**：打开结果只读缓存；`prefetch-status` 一次返回状态和正文。
  手动预取后统一刷新清单、详情、日志；残缺结果标为无效，失败可重试。
  整页缓存按图片 SHA、模型和正文完整性判定；列级缓存只补失败列。
- **缺字 SVG**：`crawl-glyphs` 按缺字码位读取当前 `report.json` / `font-patches.jsonl`
  身份映射（补丁优先），否则使用库内已缓存缩略图；只读本地文件，不联网下载。
  不再生成 `index.json`、`headword-svg.json`，资源链接脚本只准备文件目录。

首次使用先生成数据集访问层（符号链接，已 gitignore，重跑安全）；刻本字体文件
已随仓库入库（`public/fonts/`，~129MB，无需额外步骤）：

```sh
bash scripts/link-dataset.sh             # 需挂载存放扫描图的外置盘（manifest.images_dir）
python3 tools/eval/prefetch_ocr.py        # 可选：预识别近期页（默认数据集末页起，限 20 页/次）
```

## Guji 語法（.gj/3）

本次升级的背景、规则核查、算法、新旧对比、验证和迁移边界，见[排版引擎自动流式＋均式升级纪实](../docs/research/2026-11-18-排版引擎自动流式与均式升级纪实.md)。

新用户可先读 **[.gj 语法学习手册：像排活字一样排古籍](../docs/gj-syntax-guide.md)**：用康熙字典初校页的真实排版图讲解分列、字号、空位、圈注、书名框，并附罕见与边缘案例。

本项目为语法定义之唯一来源。通用词法位于 `src/parser/inline-tokens.ts`。

| 特殊符號 | 作用範圍 | 含義 |
| :--- | :--- | :--- |
| `//comment` | 至行尾 | 行注釋 |
| `@num` | 獨占一行 | 指定當前頁數 |
| 空行 / 換行 | | 不控制分列；換行結束大字與注釋作用域 |
| `$` / `¥` | 行尾（可在注釋前） | 強制換大列，格式化統一為 `$` |
| `#text` | `#` 起至物理行尾 | 後續所有文字排為大字 |
| `*` | 一個字格 | 空位，按當前字號占格；全角空格等價 |
| `(字)` / `(甲乙)` | 大字作用域內 | 一格帶圈大字；兩字合字仍占一格 |
| `【text】` | 括號內，可跨行、跨大行、跨頁 | 書名框，字號由所在行決定 |

`#` 可位于行中，例如 `小字#大字`；换行才结束大字作用域。重复 `#` 只是重复选择
大字，格式化会将 `#甲#乙#丙` 归一为 `#甲乙丙`。`古文`、标点与书名框均不切换字号。

`#*甲乙` 是一个大字空位加大字「甲乙」；`#**甲乙` 是两个大字空位加文字。
缩进没有层级上限，也不依赖文字是否为标题。旧写法迁移如下：

| 舊寫法 | 新寫法 |
| :--- | :--- |
| `# 甲乙` | `#甲乙` |
| `## 甲乙` | `#*甲乙` |
| `### 甲乙` | `#**甲乙` |

需要小字「古文」时显式换行，同一大行内写作：

```text
#甲，
古文：
#乙丙
```

旧的 `#甲，古文：乙丙` 特殊解释已删除；现在该行所有文字都是大字。
格式化按版式生成小列换行和大列空行，保留大小字边界，不为古文补标点。
大列采用流式排版，小字组在每列可用空间内均分；康熙版式为 8 列 × 12 大字格，
每大字格高两小字格。独立“古文”标签保留居中小列。标题需显式添加 `$`：

```gj
#康熙字典$
#*子集上$
#**一部$
```

已有逗号应紧贴前一个大字，逗号后换行。例如 `#三`、`，古文：` 两行格式化为
`#三，`、`古文：`；忽略中间的空行，但不跨注释行搬移逗号，也不新增标点。

带圈输入兼容全角括号、单字不闭合写法 `#(一`，以及括号内 `z`→增、数字→汉字
（`#(15)`→`#(十五)`）。格式化同时归一空格、圈注、按语符号与重复 `#`。

### 康熙字典语义

标题与字头分类位于独立的 `src/semantics/kangxi.ts`；Python 数据集工具使用
`tools/dataset/kangxi_semantics.py`，共用 `src/semantics/kangxi-rules.json` 的词表，
由同一批用例验证两端一致。以下完整写法识别为标题，不进入字头条：

- `#康熙字典$`：书名。
- `#*子集上$` 等：一个大字空位 + 十二地支之一 +「集」+「上／中／下」。
- `#**一部$` 等：两个大字空位 + 康熙 214 部首之一 +「部」。

词形、空位数和完整内容均须匹配；圈注、书名框中的文字不认作上述标题。
字头以同一行最后一个未带圈的正文汉字为宿主，排除空位、标点、注释和书名框内容。
后续小字「古文」标签后的大字归入宿主的变体，可跨行或空行；遇到释文、页界或标题
结束该归并。标题分类服务字头导航和 OCR 元数据；标题换列由 `$` 指定。

## 字體

刻本字体已随仓库入库（`public/fonts/`，url() 优先加载，见「已知偏差」），无需本地安装。
字体来源：大字 `康熙傳承版 KangXiZiDian.com`（[官網](https://www.chinesecj.com/forum/forum.php?mod=viewthread&tid=195626)）；
小字 `中華書局宋體00/02/15平面`（[官網](https://www.ancientbooks.cn/helpcore?font)）。

小字 `guji-plane0.ttf` 新增 **PUA U+E705〈口𠂹〉**，用于 @407「他」条注音；
从原有口旁与完整𠂹组合，仅限项目小字，未同步系统字体。详见
[调研核验与补录全过程](../docs/research/2026-11-18-U+E705口𠂹调研核验与补录报告.md)。

## 审计与优化边界

从仓库根目录运行：

```sh
node tools/eval/audit_gj_layout.mjs --check --strict-layout
```

该历史审计的 `--check` 比较已存 JSON/TXT 快照；旧快照仍按 `fold` 骨架显示，
不应直接与新版自动排版 IR 的 ID／源码偏移比较。日常数据校验运行：

```sh
python3 kangxi-gold/scripts/verify_dataset.py
cd guji-preview-grid && npm test
```

`test/gj2-migration.spec.ts` 使用切换前保存的 71 个已跟踪校对页的布局哈希，验证
每个字格（含空位）、圈号、书名框和阅读序文本。`test/auto-flow.spec.ts` 验证
382 页精确格式化、强制换列、跨列与跨页书名、原文定位及版式切换。
旧显式骨架的异常宽度／高度裁切仍有独立测试。设计见 [IR 设计 §12](../docs/design/guji-ir.md#12-gj3-自动流式均式排版2026-11-18)。
